Fonctionnement

  1. Mode démo (par défaut) : un moteur à base de règles rédige un résumé en une phrase et une action suggérée à partir des champs de l'événement — aucun appel externe, aucune clé requise.
  2. Azure AI Foundry (prêt, non connecté) : définir AZURE_AI_FOUNDRY_ENDPOINT et AZURE_AI_FOUNDRY_API_KEY comme variables d'environnement sur le backend fait basculer chaque analyse vers un modèle réel — même interface, résultat plus riche.
AZURE_AI_FOUNDRY_ENDPOINThttps://<ressource>.services.ai.azure.com
AZURE_AI_FOUNDRY_API_KEYsecret — à définir dans l'environnement de l'hôte, jamais dans le code
AZURE_AI_FOUNDRY_DEPLOYMENTpar défaut : gpt-4o-mini
