How it's wired

  1. Demo mode (default): a rule-based engine drafts a one-line summary and a suggested next action from the event's own fields — no external calls, no keys required.
  2. Azure AI Foundry (ready, not yet connected): setting AZURE_AI_FOUNDRY_ENDPOINT and AZURE_AI_FOUNDRY_API_KEY as environment variables on the backend switches every "Analyze" call to a real model deployment — same interface, richer output.
AZURE_AI_FOUNDRY_ENDPOINThttps://<resource>.services.ai.azure.com
AZURE_AI_FOUNDRY_API_KEYsecret — set in your host's env, never in code
AZURE_AI_FOUNDRY_DEPLOYMENTdefaults to gpt-4o-mini
